# Historical work: not the current submission

These files preserve the development trail. Their claims, plans and commands
can predate corrected experiments. Use [the consolidated manuscript](../FINAL_MANUSCRIPT.md)
for current conclusions and [the chronological ledger](results_ledger.md)
for why conclusions changed.

| Folder or file | Contents |
|:--|:--|
| `drafts/` | Superseded manuscript, explanation and literature drafts |
| `plans/` | Earlier improvement and redesign plans |
| `handoffs/` | Historical project handoff |
| `*_before_*.md` | Earlier snapshots retained for comparison |
| `results_ledger.md` | Chronological experiments, decisions and validity limits |

Old generated DOCX/PDF/HTML exports are kept locally in
`artifacts/legacy_exports/`, outside Git and the submission ZIP. Downloaded
third-party papers remain local as described in
[the literature folder](../../Similar-Papers/README.md).

Relative Markdown links were rebased during cleanup. The migration CSV's
SHA256 values record file bytes at the time of moving, before navigation
rebasing and historical notices. Frozen experiment code and protocol bytes
were not edited by this navigation cleanup.
