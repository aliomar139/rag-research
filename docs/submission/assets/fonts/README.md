# Included fonts

Newsreader and IBM Plex Sans are included for offline rendering under their
bundled SIL Open Font Licenses. `Newsreader-400.ttf` and `Newsreader-600.ttf`
are static instances of the variable source at optical size 32. The original
variable file and both license notices remain here.

Sources: [Google Fonts Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader)
and [IBM Plex](https://github.com/IBM/plex).

The HTML embeds its fonts and the PDFs embed font data. For the intended
PowerPoint appearance, install the included static Newsreader and IBM Plex
Sans faces before opening the editable deck. Text and charts remain editable.
