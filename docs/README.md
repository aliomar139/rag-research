## Detailed folders

- [Final results](../final_results/README.md): paper, offline showcase and slide deck.
- [findings](findings/README.md): individual experiment interpretations.
- [figures](figures/README.md): exported figures, numerical CSVs and source fingerprints.
- [review](review/README.md): claim audit and remaining submission details.
- [history](history/README.md): chronological ledger, earlier drafts and plans.

The [layout migration](reproducibility/layout_migration.csv) records the
cleanup relative to the previous repository layout. Main report filenames
remain in this directory so existing entry points stay recognizable.
