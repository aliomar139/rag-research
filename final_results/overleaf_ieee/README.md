# IEEE Overleaf project

1. In Overleaf, choose **New Project > Upload Project**.
2. Upload `conditional_retrieval_ieee_overleaf.zip`.
3. Set `main.tex` as the main document if Overleaf does not select it automatically.
4. Compile with pdfLaTeX.

The project uses Overleaf's `IEEEtran` class and includes both figures. The manuscript is adapted from the project's final report and keeps the reported scope and limitations. The expanded source is aimed at approximately six conference pages; final pagination can shift with Overleaf's float placement and compiler version. The figures are copied from `docs/figures`.
