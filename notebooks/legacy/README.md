# Historical executed notebooks

`reproduction.ipynb` preserves exploratory NQ/static results.
`heldout_scifact_kaggle.ipynb` preserves the later held-out SciFact workflow.
Their code and stored outputs are retained for history, not promoted to the
current indexed experiment evidence. In particular, early simulated timings
and relevance-informed corpus selection do not establish live full-corpus
acceleration. See [the ledger](../../docs/history/results_ledger.md).
