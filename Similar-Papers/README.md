# Literature research material

| Folder or file | Purpose |
|:--|:--|
| `catalogs/` | Historical search exports; spelling and duplicate extensions cleaned up |
| `reports/` | Download index and historical collection report |
| `download_all_papers.py` | Optional literature downloader using the catalog files |
| `downloaded_papers/`, `local/` | Local third-party PDFs, ignored and not redistributed |

The catalogs are research leads, not a verified bibliography. The current
manuscript cites the specific primary papers it uses. Do not import claims
from the older literature drafts without checking the cited source.

Optional downloader dependencies are in `requirements/literature.txt`.
The original Blended RAG paper is available from its
[primary source](https://arxiv.org/abs/2404.07220); the local PDF is excluded.
